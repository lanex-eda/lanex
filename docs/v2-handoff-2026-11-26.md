# LanEx v2: what was built on 26 Nov 2026, and what is still open

This branch carries almost all of `docs/audit-2026-11-15.md` (47 of its 50 work packages),
built on top of v1.0.0 (main 6c31f69) in one day by parallel builders, each with its own
research. Three independent reviews followed (run engine, security, results correctness),
and every finding was fixed. A final consistency pass then made the screens read as one app.
Use this file as the starting point for the next full audit.

## What changed for a user

| Area | New in v2 |
|---|---|
| Running | A job queue with several runs at once, sized from measured memory. A What / How / When run menu that shows the exact `librelane` command. Keep-awake on Windows, macOS and Linux. Continue after a crash or restart. Runs started in a terminal are followed live. A log view that handles 200,000 lines. |
| Runs and Compare | Bulk archive, tag, export and delete with Undo. Any metric or setting as a column. Saved views. Smooth with 1,000 runs. Compare up to 12 runs with deltas against a reference. One baseline per project. |
| Studies (sweeps) | Goals that answer a question ("fastest clock that met timing: 10 ns"). Values as lists, ranges, N points or a log spread, with a preview. Points run N at a time on the queue. Charts by value, a heatmap and a Pareto view. "Use this configuration", then "Run it once to check". LibreLane's SynthesisExploration as the synthesis goal. |
| Verify | Timing per corner: setup and hold grids, a slack histogram, the worst paths and a full path detail. Warnings grouped by code with waivers in `lanex-waivers.yaml` and "new since baseline". An HTML and Markdown sign-off-style report. A share card PNG. A run with no clock never reads Clean. |
| Layout | A key that says what each colour is. A "How to read a chip" lesson. Net names on click, net search and highlight. A Power preset. OpenROAD overlays for congestion, density, wire demand, the clock tree and the worst paths, using the sign-off constraints. A timing path from Verify drawn on the chip. KLayout in worker processes, so the page never freezes. |
| Failures and learning | Failure cards built from 17 real forced LibreLane 3.0.4 failures plus macro failures, each with a certainty label. A config check before the run. A 79-term inline glossary. Six new examples that run clean to GDS, with self-checking benches. A clock helper and a floorplan preview. |
| RTL IDE | Go to definition and references. Project search and replace with Undo. Quick open. Per-bench parameters, plusargs and time limits. Run all benches. The waveform opens at the failure. VHDL through GHDL (experimental). A schematic view. |
| Macros | A real SRAM on sky130A placed, powered and run clean to GDS from the Run button. Arrange on a to-scale floorplan with site-grid snapping and live legality. Power nets from the PDK and the LEF. An exclusion guard. An SRAM example. |
| Install and Tools | An update banner with notes. Image clean-up. PDKs removable per variant. One pinned download manifest. Windows proxy and company certificates passed into the distro. WSL memory on the Configure page. `lanex doctor`. A "Starting LanEx" window. Release builds stamped with their tag. |
| Shell | A connection-lost state that reconnects by itself. A palette that reaches projects, flow steps, Verify checks, tools, PDKs and run actions. `#flow`. One verdict vocabulary, number formatter, table standard and empty state. Every menu on the overlay stack. |
| Safety | Fixed: a trash link that could delete outside the project; script injection through the HTML report; Yosys and Tcl injection through names and settings; a planted queue that started runs; writes through planted links; lossy Replace; GET routes with side effects; a thread and log leak per run; Undo that could destroy a run. |

## How it was checked

- **Tests:** pytest grew from 1,756 to about 2,150 tests, and the frontend checks from 190 to 295. The two failures that remain are environment ones on this PC (`test_pdk::test_check_pdk_ready_no_env` and the `install_sh` uninstall test); they also fail on main.
- **Live:** every lane, fix and the final pass was checked live on real spm, Blinky and SRAM runs on private servers. Screenshots were taken at 1366, 1920 and 2560 px, in dark and light.
- **Windows installer:** checked on clean Windows 11 VMs (lane 6's EXE, c7 from 34dd06d): Welcome to a Blinky GDS, behind a proxy and fresh. A final EXE from this branch is built and VM-checked before release.

## Open decisions for the owner

- **Code signing.** Options: SignPath Foundation (free), Certum Open Source (EUR 49-69 a year). Microsoft Artifact Signing is not open to individuals in India.
- **The `deps-v1` mirror release no longer exists.** The installer and the app still list it as the hash-checked fallback. Either re-upload it (`scripts/mirror_deps.py`) or drop the mirror lines.
- **Whether to enable the drafted Windows smoke workflow** (`.github/workflow-drafts/windows-smoke.yml`).
- **Verdicts:**
  - A partial clock (some flip-flops unclocked) reads as a warning run.
  - No clock reads amber "Timing was never checked".
- **Where things are stored:**
  - Waivers in a visible project file.
  - Macros in the per-run overlay, not the config.
  - Bench settings in the browser.
- **Security edge cases:**
  - Magic reads `./.magicrc` from the folder it opens in.
  - A `config.tcl` project is evaluated by the open-time config check.
  - A symlinked `runs/` is followed.
  - `PYTHONSAFEPATH` needs Python 3.11 or later.
- **Consistency plan decisions O1-O6** in the orchestrator's notes: verdict cards, Analytics' check chips, Layout's desktop-viewer cards, Flow and Layout titles, the light-theme canvas, and "Utilisation" spelling.
- **Studies, deferred:**
  - Results retention (it deletes data).
  - Verilog parameters as axes.
  - A full-page study view.

## Known gaps

- gf180 and IHP template versions and XOR checks were not run.
- IHP and gf180 SRAM sign-off DRC fails inside the vendors' own cells.
- No IR-drop or power-density overlays.
- The `routes.py` split (audit 7e) was skipped on purpose.
- Consistency plan items 13, 14 and 16-35 remain: page bands, the error-card style, loading treatment and the shared stage strip.
- The manual console's `validate()` still checks only a program's base name.
- A real laptop sleep test, TLS inspection and PAC proxies are untested.
